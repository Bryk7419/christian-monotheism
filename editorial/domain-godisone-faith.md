# Подключение godisone.faith через Porkbun

Основной адрес: **https://godisone.faith/**. Дополнительный: **https://www.godisone.faith/**; после настройки DNS и GitHub Pages он должен перенаправлять на основной.

В репозитории подготовлены `CNAME` и `base_url`, пересобраны постоянные адреса, превью, разметка поисковиков, карта сайта и RSS. Содержимое статей и относительные пути не меняются.

## Подключение

1. Слить PR с этой настройкой в `main`. В [Settings → Pages](https://github.com/Bryk7419/christian-monotheism/settings/pages) убедиться, что **Custom domain** равен `godisone.faith`. Если поле пустое, ввести домен без `https://` и без слеша и нажать **Save**. Источник публикации — `main`, `/ (root)`.
2. В Porkbun открыть **Domain Management → godisone.faith → DNS** (значок или ссылка управления DNS рядом с доменом; иногда внутри **Details**).
3. Если уже есть записи парковки/переадресации A, AAAA или ALIAS для самого домена, заменить их записями ниже. Для `www` оставить один указанный CNAME вместо конфликтующей веб-записи. MX и TXT не удалять. NS менять не требуется, если домен использует DNS Porkbun.
4. Добавить пять записей. В Porkbun поле **Host** для корня оставить пустым; `@` в других инструкциях означает именно корень. В **Answer / Value** вписывается только указанное значение, без `https://` и пути. **TTL** — стандартное значение Porkbun (обычно 600).

| Type | Host в Porkbun | Answer / Value |
| --- | --- | --- |
| A | оставить пустым | 185.199.108.153 |
| A | оставить пустым | 185.199.109.153 |
| A | оставить пустым | 185.199.110.153 |
| A | оставить пустым | 185.199.111.153 |
| CNAME | www | bryk7419.github.io |

5. Вернуться в **Settings → Pages** и дождаться успешной проверки DNS и выдачи сертификата. Включить **Enforce HTTPS**, когда настройка станет доступна, если она ещё не включена. GitHub выдаёт сертификат; покупать его у регистратора не нужно.
6. После подключения открыть основной домен, `www`, одну статью и прежний адрес на GitHub Pages. Проверить HTTPS, переход на основной домен, поиск, изображения и сохранение пути статьи при переходе со старого адреса.

DNS нередко обновляется за несколько минут; отдельные кэши могут хранить старые данные до 24 часов. Подключение домена до обновления DNS может временно сделать старый адрес недоступным через переадресацию: выполнять эти шаги подряд.

## Что проверяется отдельно

Локальная сборка позволяет проверить ссылки, метаданные и работу сайта из корня домена. Она не подтверждает настройки в Porkbun, выпуск сертификата или реальные перенаправления GitHub Pages. Их нужно проверить после активации.
